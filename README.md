# Johannesburg SPCA Website

## Project Overview

This project is a proposed website for the Johannesburg Society for the Prevention of Cruelty to Animals (JSPCA).

The website provides visitors with information about the organisation, its services and ways that members of the public can support animal welfare.

## Website Objectives

The main objectives of the website are to:

- Increase awareness of animal welfare.
- Provide information about animal adoption.
- Provide information about volunteering and donations.
- Make contact information easily accessible.
- Encourage responsible animal care.
- Allow visitors to submit enquiries.

## Website Pages

The website contains the following pages:

1. Home
2. About Us
3. Services
4. Enquiry
5. Contact
