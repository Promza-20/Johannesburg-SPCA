# Johannesburg SPCA Website

## 1. Project Overview

This project is a responsive website developed for the Johannesburg Society for the Prevention of Cruelty to Animals (JSPCA).

The purpose of the website is to provide users with accessible information about the organisation, the services it provides, animal welfare, adoption opportunities, and ways in which members of the public can support or contact the organisation.

The website was developed as part of the Web Development (Introduction) module. The project demonstrates my understanding of basic web development concepts, including HTML and CSS, website structure, navigation, page layout, content organisation and responsive design.

The website was designed with the needs of different users in mind, including people who want to learn more about the JSPCA, people interested in adopting animals, people who want to support the organisation, and members of the public who need contact or service information.

---

## 2. Project Objectives

The main objectives of this website are to:

- Provide clear information about the Johannesburg SPCA.
- Make important information easy for users to find.
- Provide information about animal welfare and responsible animal care.
- Provide information about adoption.
- Allow users to find relevant contact information.
- Create a simple and user-friendly navigation system.
- Present information in a clear and organised way.
- Create a website that can be viewed on different screen sizes.
- Demonstrate my understanding of HTML and CSS.
- Apply the web development concepts taught in the module.

---

## 3. Target Users

The website is intended for several groups of users.

### Members of the public

Visitors who want to learn more about the Johannesburg SPCA and its work can use the website to find general information about the organisation.

### Potential adopters

People interested in adopting an animal can use the website to learn more about adoption and the animals or services available.

### Animal owners

Pet owners can use the website to find information related to animal welfare, responsible pet ownership and available services.

### Supporters and donors

People who want to support the organisation can use the website to find information about how they can contribute.

### People who need to contact the organisation

Users who have questions or require assistance can use the contact information and enquiry facilities provided on the website.

## 4. Website Structure

The website consists of multiple pages that are connected through a navigation menu.

The navigation system allows users to move between the different sections of the website without having to return to the home page each time.

The main pages included in the website are:

- Home
- About
- Services
- Adoption
- Contact

Each page has a specific purpose and contributes to the overall information structure of the website.

---

## 5. Home Page

The home page acts as the main entry point to the website.

The page also provides navigation links that allow users to access the other sections of the website.

The design of the home page focuses on making important information visible without overwhelming the user.

## 6. About Page

CSS was used to create a consistent visual identity throughout the website.

The styling was applied to the website's:

- Header
- Navigation bar
- Main content
- Images
- Buttons
- Forms
- Footer

---

## 13. Design Decisions

The website design was created with usability and readability in mind.

The layout uses clear sections and spacing to prevent information from appearing crowded.

The navigation is kept consistent across the website so that users can easily understand how to move between pages.

Images are used to support the content and provide visual information related to animals and animal welfare.

The overall design aims to communicate a caring, trustworthy and professional impression that is appropriate for an animal welfare organisation.

---

## 14. Responsive Design

The website was designed to work across different screen sizes.

Responsive techniques were used to ensure that content can adapt when the browser window becomes smaller.

The layout was tested at different screen sizes to identify problems such as:

- Content extending outside the screen
- Images becoming too large
- Navigation becoming difficult to use
- Text becoming difficult to read
- Form elements becoming difficult to use

Where necessary, CSS media queries were used to adjust the layout for smaller screens.

---

## 15. Accessibility Considerations

Accessibility was considered during the development of the website.

Alternative text was provided for images where appropriate so that users who cannot see an image can still understand its purpose.

Headings were used to organise information and make pages easier to scan.

Text and backgrounds were selected to maintain readability.

Navigation links were presented consistently across the website.

Form fields were given appropriate labels or descriptive text to help users understand what information is required.
